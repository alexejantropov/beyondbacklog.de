# beyondbacklog.de

Newsletter and blog of Alexej Antropov. Static [Astro 7](https://docs.astro.build) + Tailwind 4 site, served by the Node adapter on Replit; newsletter via Resend.

```sh
npm install
npm run dev        # http://localhost:4321
npm run ci         # check, lint, test, build, check:dist
npm start          # serve the build like Replit does
```

See `CLAUDE.md` for the commands, rules and structure.
